# Notes

`notes/` 用来存放临时分析、调研记录、agent 草稿和工作中解释材料。

这个目录不是项目事实源。

## 适合放这里

- 临时分析
- agent 调研记录
- 迁移或重构草稿
- 与真实游戏项目的对比材料
- 以后可能整理进正式文档的粗稿

## 不适合放这里

- 架构规则
- API 或场景合同
- QA 清单
- CrazyGames 提交流程
- 脚本命令合同
- 未来维护者必须当成当前事实的内容

## 提升规则

如果某份 note 变稳定，或者被反复引用：

- 把稳定结论整理进 `docs/`、`README.md`、`TEMPLATE-USAGE.md` 或 `AGENTS.md`；
- 如果 note 已被正式文档吸收，或内容已经过期，再删除该 note。

notes 可以不完整，也可以过期。正式文档不能依赖 notes；需要引用时，先把稳定结论整理进正式文档。
